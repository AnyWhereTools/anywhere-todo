# 待办 Todo

[English](README.md) · [SDK](https://github.com/AnyWhereTools/AnyWhere/blob/main/docs/plugin-services.zh.md)

从 GitHub 导入 `AnyWhereTools/anywhere-todo`，审阅并启用“待办 Todo”，搜索 `todo` 或“待办”打开。需支持 `notifications` 服务的新版 AnyWhere。

## 使用

- 快速录入后按回车保存；点击任务标题打开详情，编辑备注、清单、优先级、截止日期和提醒。窄面板使用侧滑详情，宽窗口并排展示，支持深色模式。
- “今天”包含今天截止、已逾期和今天提醒的任务；“未来 7 天”按截止日期筛选，没有截止日期时使用下一次提醒日期。“收集箱”保存未分配清单的任务；“全部待办”和“已完成”分开查看。
- 新建、重命名和删除自定义清单；删除清单只把任务移回收集箱。支持标题／备注搜索（仅当前视图），以及日期、优先级、最近添加排序。
- 截止日期与提醒时间独立设置，今天截止的任务到次日才算逾期。在“今天”快速录入自动安排到今天，在自定义清单内录入自动归入该清单。
- 完成或删除任务后可立即撤销一次；下一次成功修改或关闭页面后，撤销记录失效。快捷键：⌘ N 新建、⌘ F 搜索、⌘ S 保存、Esc 收起详情。
- 单次提醒选择未来时间。每日提醒按所选当地时刻循环；每周按所选星期和时刻循环，首次为下一次匹配，并不延迟到任意未来起始日期。
- 保存时先持久化待办，再登记系统通知。页面明确显示通知未授权或登记失败；通过系统设置允许 AnyWhere 通知后点“检查提醒状态”重试。
- 关闭页面、独立窗口或应用后，已交给系统的通知不依赖页面计时器。系统通知展示仍受通知设置、专注模式和设备状态影响；通知不是关机期间的闹钟。
- 点击通知会打开对应待办；修改会替换旧提醒，完成或删除会取消。完成重复待办会停止之后的循环；恢复未完成可重新启用循环。
- 停用搜索入口或卸载插件时，宿主取消其通知。保留数据卸载后仍可重装恢复待办；选择清除数据才删除持久内容。

最多 1000 条待办、30 个清单、50 条启用提醒、总数据 800 KiB。编辑后点击保存，再关闭窗口；数据与通知同步结果分别展示。任务只保存在本机，没有云同步或账号。

旧版任务会保留 ID、标题、备注、完成状态和原提醒时间，原提醒不会被当作截止日期。首次修改升级为 schemaVersion 2，并在 `todos.v1Backup` 保存原始数据；不支持的版本或损坏数据会暂停编辑，不覆盖原内容。请勿用旧版插件编辑新版数据。

每次修改前重读数据，编辑旧任务时检查其他窗口是否已经修改；冲突会保留当前输入并提示重新读取。宿主存储尚无事务接口，请使用一个编辑窗口，避免两个窗口同时写入。

## 开发与检查

`logic.js` 校验数据、推导日期视图和通知请求；`app.js` 保存、同步并监听宿主激活事件定位待办；`index.html` / `style.css` 构成面板。无构建步骤和第三方依赖。

```sh
node test.cjs
```

真实 WebView、原生持久化和系统通知送达测试位于 AnyWhere 的 `OfficialPluginTests`；送达测试需要系统已有通知授权，使用独立测试命名空间，不修改真实待办。宿主拥有调度和权限边界，插件不保持后台脚本。权限仅 `notifications`。MIT。
